Keep the compact list and historical-detail structure from A — Elegantný zoznam, but style all four automation tabs as native INDEXUS: Services, AI Rule Draft, Rules and Run History share page chrome, typography, global palette tokens and light/dark mode. Fixed warm editorial colors and serif typography are no longer approved.

**Why:** After selecting A, the user corrected the integration: „run history a rules nerespektuju globalne nastavenie color pallete … skor preferujem aby to bolo v jednotnom style indexus … celkovo to musi byt jednotne“.

**How to apply:** Adapt Rules and Run History to the existing Services/AI visual language, not the reverse. Preserve shared navigation, all six palettes, both modes and actual operational behavior. This does not reopen the approved rule editor.

Explain historical runs from their saved event and action logs, not from a rule's current actions. Label summary figures as the loaded-history subset rather than all-time or today's totals.

**Why:** The approved history proposal used illustrative explanations. A real rule can change after execution, and the history API returns a limited recent subset.

**How to apply:** Preserve historical evidence during visual changes; do not claim that a current rule action actually ran.
