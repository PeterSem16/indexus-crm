---
name: Priority search result design approval
description: User-approved identity and match visibility in Priority Builder search, without losing queue context.
---

Retain the existing operational badges when enriching Priority Builder results. Show the contact person, clinic/organisation, phone and email, with highlighted matching text and an explicit match reason.

**Why:** The user approved this approach because an organisation-only result hid why searching for a person's name found it. They explicitly required the original badges to remain.

**How to apply:** Treat richer search results as an extension of the existing queue interface, not a replacement queue. Show a matching secondary phone/email rather than leaving the matching value hidden; keep queue positions relative to the full eligible queue.
