---
name: Inbound popup visual hierarchy
description: Approved visual direction and semantic color rules for the Agent Workspace inbound-call popup.
---

Use a caller-first layout for the full inbound-call popup: make caller identity and CRM-card context primary, group Mission/queue, number, timer, and history on the left, and place urgency plus call actions in a separate right-hand panel.

**Why:** The user selected this direction after comparing the current design with three alternatives. The previous design used too much red, making the whole popup feel destructive rather than operational.

**How to apply:** Keep Accept as the dominant emerald action. Reserve red for repeated-caller urgency, missed-call history, and Reject. Preserve the calmer neutral/emerald shell, responsive stacked layout, and all existing call behavior when extending this UI.
