In Calls & Transcripts manager review, present the confirmed status-list outcomes, the time of each selection, and any scheduled follow-up prominently before contact details. Keep the complete contact data accessible in a collapsed disclosure rather than placing a field grid above the result.

**Why:** The contact-first drawer filled the visible height with ordinary profile fields and pushed both the actual call outcome and scheduled follow-up below the fold. The user rejected that design as unclear and explicitly approved the updated outcome-first version.

**How to apply:** Preserve the player/transcript alongside the review; show the callback target separately from when it was scheduled. A compact preview may use fixture data for visual verification, but never treat it as proof that a particular live call has recorded events.

The user explicitly wants the real Calls & Transcripts player kept as it is; the black player drawn in the canvas mockup is only a visual stand-in and must not be integrated as a player redesign. They like the clear Agent/Customer transcript layout, but actual speaker labels must come from reliable source data rather than alternating or guessing from plain transcription text.
